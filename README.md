# 启知未来 · 协同备课工作台

面向青年教师与大学生支教团队。生产网址：https://qizhi-wuhaozhe.netlify.app/ 。沿用原 Netlify 项目，不新建站点。

## 2.0 功能

- 分步备课：教学条件澄清 → 可编辑大纲确认 → 逐环节生成 → 评价与板书 → 规则检查 → Word/PPTX导出。短步骤失败后重试，不覆盖完整教案，已完成进度保存到浏览器；主动保存云端后可跨设备恢复。
- 原创教学内容库：安全、班会、科学、劳动、阅读、兴趣项目六类，每份含40分钟活动流程、重点难点、评价及资源适配；同时保留三种课件配色。没有抓取或转售第三方PPT。
- 确定性排课：根据教师、班级、课程次数与可用时段求解，检查教师与班级时间重叠，支持手动调整和CSV导出。不包含教室容量、路程或休息约束。
- 教学偏好：记录教案修改的差异；可用模型归纳候选规则，必须由用户审阅、明确确认后才用于下次生成。可修改、删除、撤销；不是模型权重训练。
- 云端个人空间：真实账号密码、独立私有快照，保存教案历史、当前备课进度、偏好与课表；并发版本检查，避免多设备静默覆盖。仅保存在浏览器的修改需主动同步。
- 在线教研组：组长创建、邀请码加入、共享教案、按教案讨论、批量JSON/ZIP导入、结构分析与归档。上传预览显示失败项。结构化备课包导入支持标准JSON；新增“文档导入与教研”支持DOCX、PPTX可提取文字以及TXT/MD/JSON与ZIP。扫描图片、PDF和旧版DOC/PPT仍不支持。
- 原本的本地任务分工、版本记录与文件交接保留在“本地交接与设置”。无关的学习工具退出主导航。

## 开发与发布

Node.js 22+；首次运行 `npm ci`，验证 `npm test`，构建 `npm run build`。静态文件输出至 `public`，函数目录 `netlify/functions`。
生产分支 `main`；授权协作者推送后由现有 Netlify GitHub连接自动部署。仅修改本机文件不会更新生产。

## 运行配置

Netlify服务端变量：`LLM_API_KEY`（Secret，Functions，Production）；默认 `LLM_BASE_URL=https://api.deepseek.com`，`LLM_MODEL=deepseek-flash`。不把密钥提交到仓库、前端或聊天中。改变量后重新部署。

云端使用 `@netlify/blobs` 的站点级强一致存储 `qizhi-studio-v2`，Functions中自动获得站点存储凭证；不需要另购服务器。存储、函数及模型均有额度或费用边界，不能保证无限免费。部署预览与生产默认共用站点存储，不用真实用户资料测试预览。

认证：Node scrypt+随机盐，服务端持久会话只保存token哈希；Cookie为HttpOnly/Secure/SameSite=Lax，7天有效；写接口同源校验、输入长度和次数限制。当前没有微信/SMS登录、找回密码、账号删除界面或企业级SSO，不伪装这些能力。请使用独立密码并妥善保管，定期归档重要教学资料。不收集学生身份资料。

## 路由与代码

- `worker/staged-api.js`：outline / phase / finish / preferences；单次模型请求42秒上限，输出逐步校验。
- `worker/studio-core.js`：课前检查、排课和可解释结构分析，共享确定性逻辑。
- `worker/template-catalog.js`：原创内容。
- `worker/studio-client.js`：工作台、流程状态、云端/团队界面。
- `server/cloud.js`：账号、个人快照、教研组权限；`netlify/functions/api.mjs`入口。真实云端行为需在Netlify验证，本地测试采用内存存储替身。
- `worker/teaching.js`：保留并扩展原教案编辑与Word/PPTX导出。
- 旧 `/api/lesson` 保留兼容，前端默认使用分步接口。

## 验证

自动测试覆盖模板、时间冲突、求解、大纲与环节校验、账号隔离、同源保护、版本冲突、团队越权及退出失效。发布前后检查真实模型、云端账户与第二会话、Word/PPTX导出；评审网络仍应由团队实测。规则分析不能替代知识核验与授课教师审阅。

## 2.1 课件设计与文档教研

课件升级为统一的版式引擎 `worker/deck-engine.js`：原创图片封面、目标页、核心问题、图文观察、活动与讨论、课后延伸等版式；长文本自动分页，教师指导语置于备注。网站预览和PPTX使用同一份布局。教师可上传1MB以内JPG/PNG作为课堂插图；“纸桥”示例自带AI生成示意图，不作为实测证据。

文档教研支持DOCX/PPTX的正文文字提取和ZIP批量处理，先在本地预览，再点击调用模型。模型输出主题、优点、风险、修改办法，每项判断必须引用原文，服务端验证引文存在后才返回。分析和原文可以分享到已加入的教研组。当前不会自动识别图中内容，也不承诺教学结论正确。

新增模块：`worker/document-review.js`、`worker/review-client.js`、`worker/deck-client.js`。封面与示意图来源见 `worker/media/README.md`。

## 3.0 AI直接制作课件

默认PPT流程改为AI设计：`/api/deck/plan`由现有DeepSeek设计整份课件的叙事结构与调色板，`/api/deck/slide`逐页生成原生元素的位置、大小、字体、颜色和教学示意。程序负责校验、预览与导出，不套用固定布局。支持4至18页、暂停续做、单页按要求重做、文字编辑和原生可编辑PPTX。旧固定版式降为折叠的离线草稿。

无需新服务账号或额外PPT生成网站，继续消耗现有模型调用额度。不会声称DeepSeek能生成位图；图片仅使用允许的本站素材或教师上传内容，概念关系可由AI设计为可编辑图形。缺少对应素材时不伪造图片来源。AI设计结果仍需教师审阅。

AI课件保存于当前浏览器，主动保存个人云端快照时同步。自选插图仍保存在本机，换设备后需要重新上传。
